# 리뷰 보고 — 수익화(AdMob + 인앱 결제)

## 요약

클라이언트 전용 수익화 MVP로 적절한 범위입니다. 스토어 출시 전 AdMob 앱 ID·배너 단위·Play 상품 등록은 운영 체크리스트(`docs/spec/11-monetization-admob-iap.md`)를 따르세요.

## 리스크 / 후속 권장

| 항목 | 내용 |
|------|------|
| 서버 검증 없음 | 비소모 구매 위변조 가능성 — 사용자 규모·요구에 맞추어 Play Developer API 검증 검토 |

| 상품 미등록 시 | 후원 화면에서 상품 로드 실패·빈 버튼 가능 — Console 설정 전까지 정상 |
