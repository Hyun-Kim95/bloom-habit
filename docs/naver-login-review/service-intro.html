1. 서비스 개요

항목내용
서비스명HabitFable (해빗페이블)
서비스 유형모바일 애플리케이션 (Android 네이티브 앱, Flutter)
업종·콘텐츠생활·생산성 — 습관 형성·기록·알림·통계 서비스
대상 이용자일상 습관을 기록·관리하려는 개인 이용자
수익 모델무료 이용 시 배너 광고, Google Play 인앱 구독(광고 제거) — 전자상거래·예약·매매 서비스 아님
회원가입소셜 로그인(Google, 카카오, 네이버) — 별도 비밀번호·웹 회원가입 폼 없음
등록 서비스 URL 안내: 네이버 개발자센터에 등록한 URL은 API 서버 및 이용약관·개인정보처리방침 공개용 웹 페이지입니다. 습관 기록·통계 등 핵심 기능은 모바일 앱에서만 제공됩니다. 본 PDF에 메뉴별 기능과 화면을 정리하였습니다.

3. 네이버 로그인 적용

  • 적용 형태: 네이버 로그인을 통한 신규 회원 가입·기존 회원 로그인
  • 비밀번호: 서비스 자체 비밀번호를 요구하지 않음
  • 가입 완료 후: 정보제공 동의 후 앱 홈(메인) 화면으로 이동
