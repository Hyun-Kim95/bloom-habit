HabitFable(해빗페이블)은 Android 습관 관리 앱입니다. 습관 생성·기록·알림·통계·고객문의를 제공하며, 웹 회원가입 페이지는 없습니다.

등록 서비스 URL은 API 서버 및 이용약관·개인정보처리방침 공개용입니다. 서비스 본체는 모바일 앱에서 제공되므로, 첨부 서비스 소개 자료(PDF)에 업종(생활·생산성), 메뉴별 기능 및 주요 화면을 정리하였습니다.

네이버 로그인은 신규·기존 회원 가입·로그인 인증에 적용합니다. 별도 비밀번호를 요구하지 않으며, 정보제공 동의 후 앱 메인(홈) 화면으로 이동합니다. 첨부 절차 캡처는 로그인 화면(네이버 버튼), 정보제공 동의, 가입·로그인 완료(홈) 순입니다.

제공 정보 활용. 이메일(필수)은 계정 관리·문의 연락에 사용합니다. 닉네임은 계정 관리 화면 표시명에 사용합니다. 프로필 사진은 계정 프로필 이미지에 사용합니다. 회원이름은 수집·표시하지 않아 API에서 미사용합니다. 각 항목별 활용 화면 캡처를 첨부하였습니다.

첨부 자료의 개인정보는 마스킹 처리하였습니다.
